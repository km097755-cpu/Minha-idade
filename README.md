# Minha idade

Programa em Java que classifica uma pessoa pela idade: criança, adolescente ou adulto.

## Como funciona
- O programa pede a idade pelo teclado.
- Se a entrada não for um número, ou estiver fora de 0 a 130, mostra "Idade inválida".
- O programa compara com as faixas:
  - até 11 anos: Criança
  - de 12 a 17 anos: Adolescente
  - 18 anos ou mais: Adulto

## Como rodar
1. Abra o projeto no IntelliJ IDEA.
2. Abra `src/Main.java`.
3. Clique no botão verde de executar.
4. Digite a idade no console e aperte Enter.

Requer Java 25 ou mais recente.

## O que pratiquei
- Variáveis e tipos (`int`)
- Leitura do teclado com `Scanner`
- Validação de entrada
- Estruturas condicionais `if`, `else if` e `else`
